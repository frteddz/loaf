# loaf

cats lie down way more than vanilla lets them. that's the whole mod.

loaf is a tiny fabric mod that makes cats stop pacing and actually flop onto the floor. every now and then an idle cat will either curl up into a loaf or sit upright for 10 to 30 seconds, then get back up. it never forces the player-sit state, so you can still call your cat over whenever you want.

pairs nicely with [Let Them Rest](https://modrinth.com/mod/let-them-rest).

## install

drop the jar in `mods`. you need fabric loader 0.20.1 or newer and java 25 or newer. no fabric api required.

built for minecraft 26.3.

## what it does

- slows the vanilla wander goal from roughly every 6 seconds to about every 60
- adds a low-priority goal that randomly poses idle cats as lying or sitting
- leaves `setOrderedToSit` alone, so player commands still take priority
